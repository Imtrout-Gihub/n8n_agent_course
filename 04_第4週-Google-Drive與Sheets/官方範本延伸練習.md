# 第 4 週：Google Drive 與 Google Sheets 五個學習範本

## 範本 1：Google Sheets 基礎讀取、新增與更新

- [n8n 官方範本](https://n8n.io/workflows/7156-get-started-with-google-sheets-in-n8n/)
- [課程 JSON](./案例範本/官方JSON/01-Google-Sheets基礎讀取新增更新.json)

### 用途

這個範本用來學習 n8n 與 Google Sheets 之間最基本的資料交換。工作流會先讀取試算表內的現有資料，再新增一列資料，最後依指定欄位找到同一列並更新內容。

可應用在報名名單、客戶資料、問卷結果、任務清單和庫存記錄等情境。

### 學習要點

- 分辨 Google Sheets 節點的讀取、Append 與 Update 操作。
- 理解 Document 與 Sheet 是不同層級的對象。
- 了解試算表第一列欄位名稱如何對應 n8n 資料。
- 學會將前一個節點的輸出映射到 Sheets 欄位。
- 學會使用不重複的 ID 或 Email 作為更新資料的配對鍵。

## 範本 2：把 Google Sheets 當成任務控制面板

- [n8n 官方範本](https://n8n.io/workflows/5102-google-sheets-ui-for-n8n-workflow/)
- [課程 JSON](./案例範本/官方JSON/02-Google-Sheets任務控制面板.json)

### 用途

這個範本將 Google Sheets 當成簡易操作介面。使用者只要把某列狀態設為 `READY`，n8n 就會處理該列，完成後將結果寫回試算表，並把狀態改為 `DONE`。

可應用在作業處理、文章審核、資料清理、待辦事項和批次產生內容等工作。

### 學習要點

- 學會以 `READY`、`PROCESSING`、`DONE` 等狀態管理工作流。
- 使用 Filter 或 Google Sheets 查詢條件，只處理符合狀態的資料。
- 使用 Loop Over Items 逐列處理多筆資料。
- 將處理結果、執行時間與新狀態寫回原列。
- 理解狀態欄位如何避免同一筆任務被重複處理。

## 範本 3：建立 Google Drive 檔案索引

- [n8n 官方範本](https://n8n.io/workflows/15456-index-new-google-drive-folder-files-into-google-sheets-automatically/)
- [課程 JSON](./案例範本/官方JSON/03-Google-Drive檔案索引至Sheets.json)

### 用途

這個範本會取得指定 Google Drive 資料夾內的檔案與資料夾，將檔名、MIME Type、副檔名、Drive 連結、File ID 和索引時間寫入 Google Sheets。

可應用在共用資料夾目錄、文件庫管理、課程教材清單、專案檔案追蹤和檔案稽核。

### 學習要點

- 學會列出指定 Drive 資料夾的檔案與屬性。
- 理解檔名、File ID、MIME Type 與 Drive URL 的差別。
- 同時讀取 Drive 與 Sheets 兩個資料來源。
- 使用 Merge 或 Filter 找出尚未寫入索引的檔案。
- 以 File ID 作為唯一鍵，避免重新執行時產生重複資料。

## 範本 4：定時將 Google Sheets 備份到 Google Drive

- [n8n 官方範本](https://n8n.io/workflows/6469-scheduled-google-sheets-data-backup-to-google-drive/)
- [課程 JSON](./案例範本/官方JSON/04-Google-Sheets定時備份至Drive.json)

### 用途

這個範本會依排程讀取 Google Sheets 資料，將資料轉換為 CSV 或 XLSX 檔案，再上傳到指定的 Google Drive 備份資料夾。檔名可加上日期與時間，保留每次備份的歷史版本。

可應用在每日報表備份、作業名單快照、庫存資料備份和稽核紀錄保存。

### 學習要點

- 使用 Schedule Trigger 建立定期執行的工作流。
- 從 Google Sheets 讀取整張表格或指定範圍。
- 將 JSON 資料轉換成 CSV 或 XLSX 檔案。
- 理解 n8n 中 JSON 資料與 binary 檔案的差別。
- 使用動態日期建立不重複的備份檔名。
- 將產生的檔案上傳到指定 Drive 資料夾。

## 範本 5：從 Google Sheets 批次建立 Google Drive 資料夾

- [n8n 官方範本](https://n8n.io/workflows/16019-create-and-share-client-folders-from-google-sheets-to-google-drive/)
- [課程 JSON](./案例範本/官方JSON/05-從Sheets建立Drive資料夾.json)

### 用途

這個範本會讀取 Google Sheets 中的客戶或專案清單，先根據代碼搜尋 Drive 中是否已有對應資料夾。如果不存在，就建立主資料夾與子資料夾，最後把資料夾 URL 寫回原試算表。

可應用在客戶文件夾、學生分組專題、新進員工文件夾、活動報名資料夾和批次建立專案結構。

### 學習要點

- 使用 Google Sheets Trigger 回應新增的表格資料。
- 從試算表取得資料夾名稱、代碼與其他建立參數。
- 先使用 Drive Search 檢查資料夾，再由 If 節點決定是否建立。
- 建立主資料夾與 Documents、Media 等子資料夾。
- 將新資料夾的 URL 與處理狀態寫回 Sheets。
- 理解「先搜尋、再建立」如何避免產生重複資料夾。
- 認識 Drive 分享權限的設定方式；課程 JSON 中的對外分享節點預設為停用。
