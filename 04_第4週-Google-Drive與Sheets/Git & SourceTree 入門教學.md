# 零基礎 Git & SourceTree 入門教學：輕鬆下載教材與交作業指南

本篇教學會帶你使用視覺化視窗工具 **SourceTree**，搭配 GitHub 的 **Fork** 功能，完成：
1. 把老師的課程專案（`roapple10/n8n_agent_course`）複製成你自己的專屬版本。
2. 用滑鼠點擊完成下載（Clone）、檔案修改、儲存進度（Commit）並上傳（Push）到自己的 GitHub。
3. **全程不需要輸入任何黑底白字的指令**，也不會改動或弄壞老師的原版教材！

---

## 觀念篇：用日常概念理解名詞

在開始操作之前，我們先用最白話的方式認識幾個名詞：

| 名詞 | 白話解釋 |
| :--- | :--- |
| **GitHub** | 放在雲端上的「檔案保險箱」，大家的程式碼與作業都存在這裡。 |
| **Fork（分叉）** | 在雲端「影印一份老師的講義」到你自己的保險箱。你在上面畫重點、寫作業，老師那邊的原版**完全不受影響**。 |
| **SourceTree** | 一個免費且漂亮的「圖形介面軟體」，讓你用滑鼠按鈕就能管理檔案版本，不用敲黑底白字的程式碼指令。 |
| **Clone（複製/下載）** | 把雲端保險箱裡的檔案，下載一份到你現在這台電腦的資料夾中。 |
| **Commit（提交進度）** | 在自己電腦上記錄：「我剛剛存檔了一版修改進度（像是建立遊戲存檔點）」。 |
| **Push（推送/上傳）** | 把電腦裡剛做好的存檔點，同步上傳備份到你自己的 GitHub 雲端上。 |

## 第一部分：安裝與設定 SourceTree

> 參考教學資源：[Sourcetree - git 的 GUI 管理軟體 - iT 邦幫忙](https://ithelp.ithome.com.tw/articles/10206852)

### 步驟 1-1：下載與安裝
1. 前往 [SourceTree 官方網站](https://www.sourcetreeapp.com/)。
2. 根據你的電腦作業系統選擇 **Download for Windows** 或 **Download for Mac**。
3. 下載完成後執行安裝檔。
4. 安裝過程中：
   * **註冊/登入**：軟體會詢問 Atlassian 帳號，可選擇直接用 Google 或 GitHub 帳號快速登入。
   * **安裝 Git 元件**：若跳出提示說電腦沒有偵測到 Git，勾選讓 SourceTree 自動幫你安裝即可。
   * **設定人員資訊**：填入你的**英文暱稱**和 **Email**（日後儲存檔案時會標註是誰改的）。

### 步驟 1-2：在 SourceTree 綁定你的 GitHub 帳號
為了之後可以把檔案上傳到自己的 GitHub，我們先綁定帳號：
1. 打開 SourceTree：
   * **Windows**：點選上方選單的 `工具 (Tools)` ➔ `選項 (Options)` ➔ `驗證 (Authentication)` 分頁。
   * **Mac**：點選左上方選單 `Sourcetree` ➔ `設定 (Settings / Preferences)` ➔ `帳戶 (Accounts)` 分頁。
2. 點擊 **新增 (Add)**：
   * **託管服務 (Hosting Service)**：選擇 `GitHub`。
   * **驗證方式 (Auth Type)**：選擇 `OAuth`。
3. 點選登入後，瀏覽器會自動彈出，點擊授權授權給 SourceTree。認證成功後會出現綠色打勾圖示，按下 **確定 (OK)** 即完成。

## 第二部分：把老師的專案 Fork 成自己的專屬 Repo

請跟著以下步驟，在雲端備份出你自己的專案：

### 步驟 2-1：開啟老師的課程專案網址
1. 打開瀏覽器，前往老師的課堂教材網址：  
   👉 [https://github.com/roapple10/n8n_agent_course](https://github.com/roapple10/n8n_agent_course)
2. 請確保你右上方已經登入了自己的 GitHub 帳號。

### 步驟 2-2：點擊「Fork」
1. 在專案畫面的**右上角**，找到一個名為 **「Fork」** 的按鈕（旁邊通常有一個小叉子圖示）。
2. 點擊 **Fork** ➔ 再點擊綠色的 **「Create fork」**。
3. 等待幾秒鐘後，你會發現網頁網址變成了：  
   `https://github.com/<你的 GitHub 帳號>/n8n_agent_course`  
   *(看到自己的帳號名稱，就代表你在雲端已經有一份完全屬於自己的教材專案了！)*

### 步驟 2-3：複製你自己的 Repo 網址
1. 在你自己的 Fork 專案頁面上，點擊綠色的 **「<> Code」** 按鈕。
2. 確保選在 **HTTPS** 標籤頁。
3. 點擊網址旁邊的 **「複製圖示」**（網址結尾一定是 `.git`）。

## 第三部分：使用 SourceTree 把教材 Clone（下載）到電腦

### 步驟 3-1：貼上網址並下載
1. 打開 **SourceTree**。
2. 點擊上方的 **「New...（新增）」** 或 **「Clone（複製）」**。
3. 在彈出視窗中依序填入：
   * **來源路徑 / URL (Source Path / URL)**：貼上剛剛步驟 2-3 複製的「你自己 Repo 的網址」。  
     *(貼上後等 SourceTree 讀取 2~3 秒，下方顯示「這是一個有效的 Git 儲存庫」即可)*
   * **目標路徑 (Destination Path)**：點擊「瀏覽」，選擇你電腦上想存放專案的資料夾（例如：`D:\Course\n8n` 或桌面的資料夾）。
   * **名稱 (Name)**：保留預設的 `n8n_agent_course` 即可。
4. 點擊右下角的 **「複製 (Clone)」**。
5. 等待進度條跑完，教材就完整下載到你的電腦資料夾中了！

## 第四部分：日常使用流程（修改 ➔ 存檔 ➔ 上傳）

在平常上課寫作業或修改設定檔時，你只需要重複以下三個步驟：

### 步驟 4-1：自由修改檔案
* 使用你習慣的編輯器（例如 VS Code、筆記本、或是管理你的 n8n 檔案）。
* 在剛剛下載的資料夾中新增、修改或刪除作業檔案。
* 隨時存檔（Ctrl + S 或 Cmd + S）。

### 步驟 4-2：在 SourceTree 中「暫存 (Stage)」與「提交 (Commit)」
1. 回到 SourceTree 視窗，點擊左側欄的 **「檔案狀態 (File Status / Working Copy)」**。
2. 你會看到剛剛修改或新增的檔案出現在清單中。
3. 點選 **「暫存所有檔案 (Stage All)」**（或在特定檔案旁勾選暫存）。
4. 在下方文字輸入框中，輸入這次修改的備忘說明（例如：「完成第四週 Google Sheets 串接練習」）。
5. 點擊右下角的 **「提交 (Commit)」** 按鈕。  
   *(此時修改已經安全地記錄在你的本機電腦上囉！)*

### 步驟 4-3：上傳到你的雲端 GitHub（Push）
1. 點擊 SourceTree 上方工具列的 **「推送 (Push)」** 按鈕。
2. 勾選你要推送的分支（預設通常勾選 `main` 或 `master`）。
3. 點擊右下角 **「推送 (Push)」**。
4. 成功上傳後，你可以打開瀏覽器回到你自己的 GitHub 頁面重新整理，就能看到剛剛上傳的作業與修改紀錄了！

## 常見疑問 Q&A（初學者安心指南）

### Q1：我這樣 Push，會不會影響到老師的原版專案？
> **答：絕對不會！**  
> 因為你是在自己 Fork 出來的倉庫底下進行 Clone 與 Push，這份倉庫的所有權是你自己的。老師的倉庫受保護且獨立，你沒有密碼與權限也推不上去，請放心大膽地練習與修改！

### Q2：我需不需要擔心 Git Submodule（子模組）的問題？
> **答：完全不需要擔心！**
> * 只要你都是在正常的課堂目錄下新增程式碼、修改 Markdown 文件或匯入匯出 n8n JSON 流程，就跟一般的專案操作完全一樣。
> * 你推送時只會更新你個人的這份專案，完全不會引發任何 submodule 的複雜衝突。

### Q3：如果在 SourceTree Push 時要求輸入密碼怎麼辦？
> **答**：請確認第一部分步驟 1-2 中，是否有先在 SourceTree 的「帳戶」設定中成功使用 **OAuth 綁定 GitHub**。只要綁定完成，Push 時 SourceTree 就會自動使用安全授權，不需要每次手動輸入密碼。
